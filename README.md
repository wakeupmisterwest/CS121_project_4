# CS121_project_4
## "horseRace.cpp" algorithm
```
functions take name of horse (number) and position of horses
Track postion of horses inside array (length of 15)
Create race track using strings
Take user input to coin flip determing whether a horse goes forward (0/1)
Keep looping until horse hits end of track
Print name of horse that wins
```
## "advance" algorithm
```
use random number generation to coin flip
if 0 stay, if 1 move
```

```
loop through horse array

```
